# Changelog

## 0.20.1
_v0.20.1 includes platform-specific fixes for macOS and Windows, alongside official Linux ARM64 (aarch64) build support._

### Redis / Valkey / Upstash
* Fixed **SSH Key File Path** (macOS): Clicking the folder icon now correctly opens the file selection dialog.

> _Note: Full Redis and Valkey support will return in v0.21.0._

### Cloudflare R2
* Fixed **Upload Center** (macOS): Clicking the file or folder icon now correctly opens the file or folder selection dialog.

### Windows
* Fixed **Installer**: Resolved missing Visual C++ Runtime DLL errors that prevented the app from launching.

### Linux
* Added **ARM64 Support**: Added Linux `aarch64` AppImage build (`keyscope-v0.20.1-linux-aarch64.AppImage`).
