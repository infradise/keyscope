# Changelog

## 0.30.0
_Introducing Resend, HTTP Client, and Visual Diff, alongside hardened macOS App Sandbox and OS Keychain security._

> _Note: Redis and Valkey will be unlocked in v0.31.0._

### Redis & Valkey Ecosystem
_Redis / Valkey / Upstash / GCP Memorystore / AWS ElastiCache_

* Added **Active Connections List**: Real-time tracking in the sidebar panel upon connection and disconnection
* Added **Switchable Single Connection** support for the Free plan
* Added **Unlimited Active Connections** support for the Pro plan
* Added **In-App Pro Trial**: Free upgrade trial now available for waitlist users
* Added **Active Connection Counter**: Displays total active connections
* Improved **Connection Manager**: Automatically opens the selected server when entering edit mode
* Added **Server Deletion**: Delete servers directly from the server list
* Improved **Auto-Navigation**: Automatically switches to the console view upon successful connection
* Added **CLI Console**: Features export, query execution, syntax highlighting, query timing, auto-completion, and Ubuntu-style shortcut (Ctrl+Alt+T)

### Resend
* Added **OS Keychain Integration**: Securely stores connection credentials (API Key, etc.) in the OS Keychain
* Added **Key Configuration**: Resend API Key
* Added **Email Sender Form**: Includes Sender, Recipients, Subject fields, and Send Email button
* Added **HTML Template Editor**
* Added **Live Preview**: Built-in WebView supporting macOS, Windows, and Linux (Ubuntu & Fedora)

### HTTP Client
* Added **Multi-Method Support**: Full support for GET, POST, PUT, PATCH, DELETE, HEAD, OPTIONS, and Custom HTTP methods
* Added **Response Preview Formats**: Comprehensive preview support for raster images (PNG, JPEG, GIF, WEBP, BMP, ICO, AVIF, TIFF, HEIC/HEIF), vector graphics (SVG), embedded PDFs, and structured data (JSON, XML, HTML, Plain Text)
* Added **Postman Collection Interoperability**: Native Postman v2.1 Collection JSON import/export parser with hierarchical tree viewer
* Added **Dynamic Environment Manager**: Supports `{{variable}}` substitution, multiple environments (Dev/Staging/Prod), and secure masked variables
* Added **Request & Response Inspector**
  * Request Builder: Dynamic Key-Value table editors for Query Params & Headers, and monospace JSON Raw Body editor
  * Response Viewer: Real-time tracking of HTTP status codes, execution time (ms), response size, formatted Pretty JSON, Raw text, Markdown Preview, and response headers table
* Added **Resizable Splitter UI**: Interactive horizontal and vertical drag splitters to dynamically adjust sidebar width and request/response panel heights
* Added **Request History Tracking**: Automatically logs past requests with status codes and instant re-execution
* Added **Data Persistence**: Local storage engine ensuring Collections and Request History automatically persist across app restarts

### Visual Diff
* Added **2-Way Visual Diff Workspace**: Dual-pane code comparison workspace featuring synchronized 2D (vertical & horizontal) scrolling and fluid Bezier curved gutter connections
* Added **File & Recursive Folder Comparisons**: Native support for single files and recursive directory tree comparisons with visual change indicators
* Added **Inline Word & Token-Level Highlighting**: Granular word- and character-level change detection using tokenized diff algorithms for modified lines
* Added **Synchronized Dual-Pane Horizontal Scrolling**: 1:1 linked horizontal scrollbars dynamically scaled to overall maximum line length across both viewports
* Added **Pinned Line Numbers & Merge Actions**: Viewport-edge sticky layering with opaque background masking for line numbers and merge controls, keeping them fixed during horizontal panning
* Added **Smart Text Overflow Tooltips**: Composited overlay tooltips with text truncation detection, smart partial drag-selection vs. full-path copying, screen boundary clipping protection, and visual feedback
* Added **Interactive Merging & Write-Back**: Line-level inline merge actions (`◀`, `▶`), global "Merge All", direct disk saving, and exit protection for unsaved changes
* Added **High-Performance Async Engine**: Multithreaded background processing preventing UI freezes when comparing large files (10,000+ lines)
* Added **Data Stack Interoperability**: Direct Visual Diff launching for Redis/Valkey values, K8s Manifests, and D1 records with automatic JSON key sorting and semantic diffing
* Added **Quick Launch Compare Dialog**: Modal launcher supporting Left, Right, Ancestor, and Merge file path inputs
* Added **Bezier Gutter Ribbon**: Custom Bezier ribbon rendering supporting 1:N, N:1, insertion/deletion geometries, dashed guide lines, block badges, and 3px single-sided anchor lines
* Added **Independent Dual Headers**: Lightweight headers displaying absolute paths, instant clipboard copying with visual feedback, disk reloading, and central panel swapping (`<->`)
* Added **Desktop Shortcuts & Status Bar**: Native keyboard shortcuts (`Cmd/Ctrl+S`, `F7` / `Shift+F7`) and bottom status bar with real-time stats and jump navigation
* Added **Unified Patch Generator**: Export standard `.patch` files or copy Unified Diff directly to the clipboard
* Added **Comparison History Manager**: Persistent storage for historical diff sessions with instant re-launch, path editing, and item deletion

### Custom Caption Bar & Desktop Shell
* Added **Unified Custom Caption Bar**: Integrated cross-platform frameless title bar featuring brand logo, search launcher, workspace layout toggles, and system notification controls
* Added **Interactive Search & Command Palette Bar**: Quick-access search bar with `⌘K` / `Ctrl+K` shortcut indicator
* Added **Pro Upgrade Badge**: Interactive status badge providing direct access to license management and upgrade contexts
* Added **Workspace Layout Toggles**: Instant layout controls for toggling the left sidebar, bottom terminal/log panel, and right inspector panel
* Added **macOS Traffic Light Auto-Alignment**: Dynamic vertical centering and auto-alignment for macOS window control buttons
* Added **Zero-Latency Fullscreen Synchronization**: Seamless margin adjustment and frame-drop prevention during OS space transitions
* Added **App Exit Confirmation Dialog**: Custom dark-themed exit confirmation modal triggered on native close actions across macOS, Windows, and Linux

### macOS Security & Architecture
* Improved **App Sandbox & OS Keychain**: Resolved architectural trade-offs between Apple App Sandbox compliance, OS Keychain integration, and native file/folder access permissions—ensuring hardened user security without compromising file I/O capabilities

### Common
* Improved **File Operations**: Optimized file and folder access handling using stable OS-native implementations
* Improved **Welcome Screen**: Made data stack selection buttons responsive
* Added **System Language Auto-Detection**: Automatically detects and applies the OS system language on launch when supported
* Added **Workspace State Retention**: Preserves session state and work progress when switching Dev Stacks via the Activity Bar or Welcome Screen
