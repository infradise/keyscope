# Changelog

## 0.34.0

*Maintenance release focusing on Linux system compatibility, automatic keyring daemon startup and polling on Manjaro, and dynamic WebKit helper path resolution for aarch64 and x86_64 architectures.*

### Added

* **Keyring Daemon Auto-Start & Polling**: Implemented automatic service initialization and continuous status polling for inactive keyring daemons on Manjaro and other Linux environments (#2).

### Fixed

* **Linux AppImage Permissions**: Resolved permission error when preparing WebKit helper binaries on Ubuntu 26.04 and other Linux environments (#1).
* **Arch Linux WebKit Helper Architecture Path**: Fixed an issue where WebKit helper binaries failed to load due to a hardcoded target architecture directory path for `aarch64` and `x86_64` systems (#3).

### Binary Sizes

* Linux aarch64 (.AppImage): 66.3 MB
* Linux x86_64 (.AppImage): 70.3 MB
