# Changelog

## 0.33.0

*Maintenance release featuring Linux system dependency checks with interactive setup, feature renamings (Mail Sender & Text Editor), standalone macOS architecture builds, and Settings UI localization fixes.*

### Added

* **Linux Pre-Launch System Setup**: Implemented a 3-step startup check that detects missing system dependencies (OS Keyring daemon, Secret library, WebKit helpers) and automatically prompts for user authorization to install the required packages.
* **Standalone macOS Architecture Builds**: Separated macOS release packages into distinct Apple Silicon (arm64) and Intel (x86_64) binaries.

### Fixed

* **Open Source License Display**: Resolved an issue where the Open Source License page rendered as a grey screen in Settings.
* **Linux Local Terminal**: Resolved an issue where executing certain commands failed due to a missing `libffi.so.6` dependency.

### Improved

* **Settings UI**: Optimized font sizing and improved text truncation ("...") for better readability.
* **Resizable Sidebar**: Added a split-pane sidebar in Settings to easily view long localized menu labels (e.g., Japanese, Russian).

### Changed

* **Mail Sender**: Rebranded from 'Resend' to support additional email dispatch provider APIs.
* **Text Editor**: Rebranded from 'Memo Pad' for a more intuitive and user-friendly experience.
