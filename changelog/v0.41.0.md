# Changelog

## 0.41.0

⚡ **Major Release: Cross-Platform Auto-Updates & Smart Hybrid Engine**

*Keyscope v0.41.0 introduces an automated update engine across macOS (#4), Windows (#5), and Linux (#6), featuring adaptive network probing and an AppImage delta updater.*

### Auto Updater (New)

* Added **Update UX**: Automatically checks for updates on app launch and displays an `[Update]` badge on the caption bar. Clicking the badge reveals release notes and handles the download, install, and restart process. Manual checks are available via `Settings > Version`.
* Added **Smart Hybrid Zsync (Linux)**: Introduced a dual-routing AppImage update engine. It skips block matching on fast networks for direct full downloads, while utilizing bandwidth-saving delta updates on slow connections.
* Added **Adaptive Network Probing**: Automatically measures network conditions (High/Medium/Low) in real-time (0.3s) to determine the download strategy before starting.
* Added **Dynamic Worker Scaling**: Scales up to 8 concurrent download threads to bypass CDN single-connection throttling and optimize download speeds on fast networks.
* Added **Lossless Error Recovery**: Ensures stable updates in unstable network environments by re-queueing failed chunks and downgrading worker counts upon HTTP 429 (Too Many Requests).
* Added **Memory-Safe File I/O**: Designed with AsyncMutex-backed direct disk appending to eliminate Out-Of-Memory (OOM) risks during package downloads.
* Improved **Zero-Configuration Experience**: Removed manual thread configurations and delta toggles. The engine autonomously determines optimized settings based on network environment.

### Windows

* 📌 **Windows Users**: The installation path has changed from `perMachine` to `perUser`. A clean reinstall is recommended by uninstalling the current version first.
* Changed **Install Directory**
  * Changed Package `InstallScope` (`PerMachine` -> `PerUser`)
  * Changed Installation Root Folder (`Program Files` -> `AppData\Local`)

### Linux

* 📌 The attached `.zsync` file is used internally by the Linux AppImage delta update engine. Manual download is not required.
