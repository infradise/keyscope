# Changelog

## 0.30.2
_Hotfix release resolving Linux app launch dependencies and VM rendering issues._

### Fixed
* Fixed **Linux App Launch Issue**: Resolved missing runtime library dependencies (Crypto & WebKit) by bundling embedded libraries into Linux release packages
* Fixed **VM Rendering Black Screen**: Resolved black screen failures in virtual machine environments (e.g., RHEL 9.6 aarch64) by introducing automatic VM detection and the `--enable-software-rendering` CLI option

### Changed
* Changed **Linux Language Fallback**: Defaults UI language to English when Korean, Japanese, or Vietnamese locales are detected on Linux to prevent font rendering issues caused by missing native fonts

### Improved
* Improved **Linux Distribution & VM Compatibility**: Verified seamless execution across major Linux distributions (RHEL, Ubuntu, Debian, Fedora, openSUSE, etc.)

---

> **Linux Environment Notes:**
> * Verified compatibility across major Linux distributions (RHEL 9+, Ubuntu 18+, Debian 11+, Fedora 39+, openSUSE 15+, Kali 2021.1+, Alma 9+, Rocky 9+, openSUSE 15.4+, SLE 15 SP6+, Oracle 9+, CentOS 9+, etc.).
> * **Debian 11 Users:** Requires `libgles2` (18KB). Installation guide and packages will be soon available on the Keyscope website.
