# Changelog

## 0.20.0
_v0.20.0 focuses on Cloudflare R2. Redis and Valkey support will return in v0.21.0._

### Kubernetes
> _No major updates in this release._  
> _Note: Partial resource support (e.g., pods) is planned for v0.30.0+._

### Redis / Valkey / Upstash
> _No major updates in this release._  
> _Note: Redis and Valkey support will return in v0.21.0._

### Cloudflare R2

* Added **Upload Center**  
  - Drag & drop bulk upload support  
  - Automatic folder hierarchy creation  
  - Real-time upload status & progress tracking  
  - Batch upload rollback support  

* Added **Object Management**  
  - File editing & large upload/download support  
  - Smart renaming with progress tracking  
  - Bulk deletion support  

* Added **Lifecycle Rules**  
  - UI to prevent silent billing leaks from incomplete multipart uploads  
  - Default auto-abort after 7 days (customizable in 1-day increments)  

* Improved **Storage Integration Core Workflow**  
  - Streamlined bucket creation, folder management, and safe deletion  

### Cloudflare D1
> _No major updates in this release._
