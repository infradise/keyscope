# Changelog

## 0.40.0

⚡ **Major Release: Comprehensive Kubernetes Support**

*Keyscope v0.40.0 introduces native, multi-cluster Kubernetes management designed for ultra-fast performance and seamless developer workflows.*

### Kubernetes
* Manage multiple clusters simultaneously with native multi-cluster support  
* Support for 50+ Kubernetes resource types with intuitive custom icons  
* Real-time resource streaming for instant monitoring and superior rendering  
* Integrated YAML editor with Read-Only and Interactive Edit modes  
* Native shell access and real-time Pod log streaming  
* Securely sync and store `~/.kube/config` credentials in OS Keychain  
* Preserve namespace context across different resource views  
* Fast search and filtering optimized for heavy namespace environments
