# Changelog

## 0.32.0

*Major release introducing the SSH Client Toolkit with multi-tab support and OS-native keychain integration.*

### Added

* Added **SSH Client Core Architecture**: Integrated remote SSH server connections supporting Password and Private Key (PEM, RSA) authentication with passphrase protection
* Added **Multi-Session Tab System**: Supported multi-tab management for concurrent SSH sessions with dynamic terminal viewport resizing and connection status indicators
* Added **Connection Manager Sidebar**: Implemented a split-pane layout with a sidebar for managing saved SSH connections, enabling direct session editing and tab launching
* Added **OS-Native Credential Storage**: Integrated OS-native Keychain/Keystore to securely store credentials, including host info, passwords, and private key paths
* Added **Persistent UI Settings**: Supported persistent configurations for last-connected sessions and terminal UI preferences
* Added **Input Validation**: Added Host/IP and Port field validation to prevent invalid connection attempts
* Added **i18n & Localization**: Added 9-language localization support across the SSH Client UI and connection manager dialogs
