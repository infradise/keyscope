# Changelog

## 0.44.0

In this release, the synchronization scope has been upgraded from the single `~/.kube/config` file to the entire `~/.kube` directory. Additionally, the Toolkit, Settings, and Notification icons have been moved from the Activity Bar to the bottom Status Bar. The Activity Bar has been repurposed to serve exclusively as a favorites hotbar for your K8s clusters.

### Added
- **Inline Cluster Manager Home**: Introduced an inline cluster explorer directly rendered in the main workspace upon app launch, removing the need for a separate pop-up window.
- **Multi-Kubeconfig Directory Scan**: Expanded discovery beyond `~/.kube/config` to automatically scan all configuration files in `~/.kube/` and parse all contained contexts.
- **File Metadata & Status Columns**: Added `Source Path`, `Modified Date`, and `Access Date` columns to the cluster grid, alongside `Status` indicators and favorite toggles.
- **Table Header Sorting**: Implemented ascending/descending toggle sorting across all column headers with visual state indicators (▲/▼/↕), defaulting to `Access Date` in descending order.
- **Multi-Cluster Grouping & Connection**: Added the `Connect Selected (N)` workflow to batch-connect single or multiple clusters as a unified session group (`Multi-Cluster Group`).
- **Activity Bar Pinning & Context Menu**: Added support for dynamically pinning favorite cluster groups to the left Activity Bar, featuring right-click context menu actions (Rename, Edit Members, Reconnect, Disconnect, Remove) with persistent storage via `SharedPreferences`.

### Changed
- **Revamped Application Startup Flow**: Streamlined the entry point to bypass introductory screens and navigate directly into cluster management and Kubernetes workflows.
- **Cluster Management UI Transition**: Converted the standalone pop-up modal into a full-width, responsive workspace data grid.
- **Toolkit Relocation**: Relocated the Toolkit (HTTP Client, SSH Client, Visual Diff, Local Terminal, Mail Sender) from the Activity Bar to the right side of the Status Bar.
- **Settings & Notifications Relocation**: Moved the Settings and Notification icons from the Activity Bar to the left side of the Status Bar.

### Removed
- **Static WelcomeScreen**: Removed the legacy landing page displaying static Data Stack and Toolkit cards.
- **Cluster Manager Pop-up Modal**: Deprecated and removed the previous pop-up dialog interface for cluster selection.

## Note
📌 The legacy Welcome Screen, which allowed pinning Data Stack and Toolkit items to the Activity Bar, has been removed. We highly recommend unpinning all items in the previous version before upgrading to this new release. (Alternatively, you can perform a factory reset via **Settings > Reset Settings**).
