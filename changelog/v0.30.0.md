# Changelog

## 0.30.0-rc.2
_Restoring Redis & Valkey support, introducing Resend & HTTP Client, alongside hardened macOS App Sandbox and OS Keychain security._

### Redis & Valkey Ecosystem
_Redis / Valkey / Upstash / GCP Memorystore / AWS ElastiCache_

* Restored **Redis & Valkey Support**
* Added **Active Connections List**: Real-time tracking in the sidebar panel upon connection and disconnection
* Added **Switchable Single Connection** support for the Free plan
* Added **Unlimited Active Connections** support for the Pro plan
* Added **In-App Pro Trial**: Free upgrade trial now available for waitlist users
* Added **Active Connection Counter**: Displays total active connections
* Improved **Connection Manager**: Automatically opens the selected server when entering edit mode
* Added **Server Deletion**: Delete servers directly from the server list
* Improved **Auto-Navigation**: Automatically switches to the console view upon successful connection
* Added **CLI Console**: Features export, query execution, syntax highlighting, query timing, auto-completion, and Ubuntu-style shortcut (Ctrl+Alt+T)

### Resend
* Added **OS Keychain Integration**: Securely stores connection credentials (API Key, etc.) in the OS Keychain
* Added **Key Configuration**: Resend API Key
* Added **Email Sender Form**: Includes Sender, Recipients, Subject fields, and Send Email button
* Added **HTML Template Editor**
* Added **Live Preview**: Built-in WebView supporting macOS, Windows, and Linux (Ubuntu & Fedora)

### HTTP Client
* Added **Multi-Method Support**: Full support for GET, POST, PUT, PATCH, DELETE, HEAD, OPTIONS, and Custom HTTP methods
* Added **Postman Collection Interoperability**: Native Postman v2.1 Collection JSON import/export parser with hierarchical tree viewer
* Added **Dynamic Environment Manager**: Supports `{{variable}}` substitution, multiple environments (Dev/Staging/Prod), and secure masked variables
* Added **Request & Response Inspector**
  * Request Builder: Dynamic Key-Value table editors for Query Params & Headers, and monospace JSON Raw Body editor
  * Response Viewer: Real-time tracking of HTTP status codes, execution time (ms), response size, formatted Pretty JSON, Raw text, Markdown Preview, and response headers table
* Added **Resizable Splitter UI**: Interactive horizontal and vertical drag splitters to dynamically adjust sidebar width and request/response panel heights
* Added **Request History Tracking**: Automatically logs past requests with status codes and instant re-execution
* Added **Data Persistence**: Local storage engine ensuring Collections and Request History automatically persist across app restarts

### macOS Security & Architecture
* Improved **App Sandbox & OS Keychain**: Resolved architectural trade-offs between Apple App Sandbox compliance, OS Keychain integration, and native file/folder access permissions—ensuring hardened user security without compromising file I/O capabilities

### Common
* Improved **File Operations**: Optimized file and folder access handling using stable OS-native implementations
* Improved **Welcome Screen**: Made data stack selection buttons responsive
