# Changelog

## 0.50.0

### Added
* Data Stack for Redis, Valkey, Upstash, R2, and D1
* Live Keyspace Inspector, stats, and log viewer
* Resizable Console with key sync and DB switching
* OS Keychain support for Cloudflare R2 and D1
* TLS/SSL, Readonly, SSH & tunneling in Advanced tab
* Persistent language selection settings

### Changed
- Bumped Flutter to 3.47.8 (Dart 3.13.7)

### Security
* Fixed MitM security flaw (CWE-295) via Dart 3.13.7 update
> Note
> A security vulnerability has been identified in the Dart engine used by Keyscope v0.44.0 for network communications. The bundled BoringSSL library in Dart 3.13.5 does not read the Windows certificate blocklist, which may expose users to man-in-the-middle (MitM) attacks (CWE-295).
>
> To address this issue, Keyscope v0.50.0 has been released with Dart 3.13.7, which includes the security fix.

📌 All affected versions (v0.44.0 and earlier) have been removed and are no longer available for download or auto-update.
