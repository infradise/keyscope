# Changelog

## 0.31.0

*Major release introducing the built-in Local Terminal Toolkit and OS-native font fixes for Visual Diff.*

### Added

* Added **Local Terminal Core Architecture**: Integrated native PTY process I/O with automatic OS default shell detection (`Zsh`, `Bash`, `PowerShell`) and dynamic terminal viewport synchronization for flawless resizing
* Added **Multi-Session Tab System**: Introduced multi-session tab management featuring seamless tab switching, session creation/deletion, and double-click tab renaming
* Added **Terminal Action Bar & Search**: Integrated a dedicated utility bar for buffer clearing, log exporting, clipboard actions, font size zooming, and real-time in-terminal text search with match counters
* Added **ANSI Parser & Theme Binding**: Implemented custom ANSI sequence parsing seamlessly mapped to Keyscope's 16-color palette and brand theme
* Added **Keyboard Shortcuts & PTY Signals**: Supported cross-platform hotkeys (`Cmd/Ctrl+C/V`, `Cmd/Ctrl+F`) and native terminal control signals (`Ctrl+C`, `Ctrl+D`, `Ctrl+Z`, `Ctrl+L`)
* Added **Context Overlays & Settings**: Added right-click context menus, process termination restart banners, and persistent configuration for custom shell paths and font preferences
* Added **i18n & Test Suite**: Added full 9-language localization coverage and comprehensive unit test suites for session state management

### Fixed

* Fixed **Visual Diff Monospace Fonts**: Updated default code diff rendering fonts on Windows and Linux to match OS-native monospace fonts (macOS remains unchanged)
